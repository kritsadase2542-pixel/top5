📊 4. ประวัติการมาเรียน

📊 กราฟเปรียบเทียบการเข้าเรียน (ชาย-หญิง)

🟦 สีฟ้า = นักศึกษาชาย | 🟥 สีชมพู = นักศึกษาหญิง

📊 กราฟสรุปเปอร์เซ็นต์การเข้าเรียนรายบุคคล

🟩 สีเขียว = ผ่านเกณฑ์ | 🟥 สีแดง = ไม่ผ่านเกณฑ์

✅ ตารางประวัติการเข้าเรียน

เลขที่รหัสชื่อ-นามสกุลวันที่และเวลาวิชารายละเอียดสถานะจัดการ

📝 5. ประวัติการส่งงาน

📊 กราฟเปรียบเทียบการส่งงาน (ชาย-หญิง)

🟦 สีฟ้า = นักศึกษาชาย | 🟥 สีชมพู = นักศึกษาหญิง

📊 กราฟสรุปร้อยละการส่งงานรายบุคคล

🟩 สีเขียว = ผ่านเกณฑ์ | 🟧 สีส้ม = เสี่ยง (ต่ำกว่าเกณฑ์ไม่เกิน 5%) | 🟥 สีแดง = ไม่ผ่านเกณฑ์

📋 รายงานนักศึกษาที่ยังส่งงานไม่ครบ

เลขที่รหัสชื่อ-นามสกุลส่งแล้ว / งานทั้งหมดงานที่ยังไม่ได้ส่ง

📝 ตารางประวัติการส่งงาน

เลขที่รหัสชื่อ-นามสกุลวันที่และเวลาวิชาชื่องานคะแนน / เต็มจัดการ

✉️ รายการใบลา

📊 กราฟเปรียบเทียบการลา (ชาย-หญิง)

🟦 สีฟ้า = นักศึกษาชาย | 🟥 สีชมพู = นักศึกษาหญิง

📊 กราฟสรุปการลา (รายบุคคล)

🟦 สีฟ้า = ชาย | 🟥 สีชมพู = หญิง | ⬛ สีเทา = ไม่ระบุ
เลขที่รายละเอียดวันลาวิชาชื่อ-นามสกุลเหตุผลจัดการ

🎯 ระบบกรอกคะแนนสอบ (จัดกลุ่มตามห้อง)

📊 กราฟเปรียบเทียบคะแนนสอบ (ชาย-หญิง)

🟦 สีฟ้า = นักศึกษาชาย | 🟥 สีชมพู = นักศึกษาหญิง

📊 กราฟสรุปร้อยละคะแนนสอบรายบุคคล

🟧 สีทอง = สอบผ่าน | 🟥 สีแดง = สอบไม่ผ่าน
รหัสชื่อ-นามสกุลได้คะแนน / เต็มสถานะประกาศจัดการ

⭐ ระบบสรุปคะแนนและตัดเกรด

* ระบบจะรวมคะแนนจาก: คะแนนเก็บ(สแกน/ส่งออนไลน์) + กลางภาค/ปลายภาค + พิเศษ

📊 สรุปผลการเรียนและกราฟเกรด (เปรียบเทียบชาย-หญิง)

🟦 สีฟ้า = นักศึกษาชาย | 🟥 สีชมพู = นักศึกษาหญิง

📊 กราฟสรุปเกรด (รายบุคคล)

🟩 A | 🟦 B+, B | 🟨 C+, C | 🟧 D+, D | 🟥 F
เลขที่ รหัส ชื่อ-นามสกุล คะแนนเก็บ (Auto) กลางภาค ปลายภาค พิเศษ รวมทั้งหมด เกรด สถานะ จัดการ

🏕️ ระบบบันทึกการเข้าร่วมกิจกรรม / อบรม

📸 สแกน QR Code ลงชื่อเข้าร่วมกิจกรรม / อบรม

รองรับทั้ง QR Code จากบัตรประจำตัวนักศึกษา และ QR Code จากระบบบันทึกข้อมูลนักศึกษา คณะวิทยาศาสตร์ สาขาชีววิทยา สำหรับลงชื่อเช็กเข้าร่วมกิจกรรม/อบรม

📊 กราฟเปรียบเทียบการเข้าอบรม (ชาย-หญิง)

🟦 สีฟ้า = นักศึกษาชาย | 🟥 สีชมพู = นักศึกษาหญิง

📊 กราฟสถิติการเข้าอบรม (แต่ละกิจกรรม)

📊 ประวัติผู้เข้าร่วมกิจกรรม
